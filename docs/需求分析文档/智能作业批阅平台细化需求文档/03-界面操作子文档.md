## 1. 界面设计总则

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| 一致性 | 同类操作使用一致的交互方式，降低用户学习成本 |
| 易用性 | 符合用户操作习惯，减少不必要的点击和跳转 |
| 反馈性 | 操作后及时给予明确反馈，告知用户当前状态 |
| 容错性 | 关键操作需确认，支持撤销或回退 |
| 效率性 | 常用功能便捷可达，支持快捷键和批量操作 |

### 1.2 技术规范

| 端 | UI 框架 | 组件库 |
|---|--------|--------|
| PC 端 | Vue 3 (Options API) | Element Plus |
| 移动端 H5 | uni-app (Vue 2 Options API) | uView UI 2.x |

### 1.3 响应式设计

| 端 | 最小宽度 | 推荐分辨率 |
|---|---------|-----------|
| PC 端 | 1280px | 1920×1080 |
| 移动端 | 320px | 375×667 (iPhone SE) |

## 4. 交互规范

### 4.1 通用交互规则

| 交互类型 | 规范 |
|---------|------|
| 加载状态 | 显示 Loading 动画，超过 3 秒显示进度提示 |
| 操作成功 | Toast 提示"操作成功"，1 秒后自动关闭 |
| 操作失败 | Toast 提示失败原因，支持关闭 |
| 二次确认 | 删除、提交等关键操作需二次确认 |
| 表单校验 | 提交前校验，错误字段标红并显示错误信息 |
| 数据刷新 | 支持下拉刷新（移动端）/点击刷新（PC 端） |
| 空状态 | 无数据显示空状态图示和提示文字 |

### 4.2 表单交互规范

| 字段类型 | 交互规范 |
|---------|------|
| 文本输入 | 聚焦时显示边框高亮，失焦时校验 |
| 数字输入 | 支持上下箭头调整，限制最小/最大值 |
| 日期选择 | 弹出日期选择器，支持快捷选择（今天、明天等） |
| 下拉选择 | 弹出下拉列表，支持搜索（数据多时） |
| 多选 | 弹出多选弹窗，显示已选数量 |
| 文件上传 | 显示上传进度，支持拖拽上传 |

### 4.3 列表交互规范

| 交互类型 | 规范 |
|---------|------|
| 分页 | 显示总条数、当前页、总页数，支持跳转 |
| 排序 | 点击表头排序，显示排序方向标识 |
| 筛选 | 筛选条件显示在列表上方，支持展开/收起 |
| 批量操作 | 勾选后显示批量操作栏 |
| 搜索 | 支持模糊搜索，实时过滤或点击查询 |
