### 1.3 核心表字段设计

所有表均采用以下基类字段：
- ID: VARCHAR(32) 主键（雪花 ID）
- CJR: VARCHAR(32) 创建人
- CJSJ: DATETIME 创建时间
- GXR: VARCHAR(32) 更新人
- GXSJ: DATETIME 更新时间
- LJSC: INT 逻辑删除（0：显示，1：隐藏）

#### TB_B_HOMEWORK_PUBLISH (作业发布表)

```sql
CREATE TABLE TB_B_HOMEWORK_PUBLISH (
    ID VARCHAR(32) NOT NULL PRIMARY KEY COMMENT '主键（雪花 ID）',
    TITLE VARCHAR(200) NOT NULL COMMENT '作业标题',
    DESCRIPTION TEXT COMMENT '作业描述',
    TEACHER_ID VARCHAR(32) NOT NULL COMMENT '发布教师 ID',
    SUBJECT_ID VARCHAR(32) NOT NULL COMMENT '学科 ID',
    HOMEWORK_TYPE VARCHAR(20) NOT NULL COMMENT '作业类型：KEHYZY=课后作业/KTLY=课堂练习/DYCS=单元测试/QZKS=期中考试/QMKS=期末考试',
    CLASS_IDS VARCHAR(500) NOT NULL COMMENT '发布班级 ID 列表（逗号分隔）',
    ESTIMATED_DURATION INT COMMENT '预计完成时长（分钟）',
    PUBLISH_DATE DATE NOT NULL COMMENT '布置日期',
    DEADLINE DATETIME NOT NULL COMMENT '提交截止日期',
    STATUS VARCHAR(20) DEFAULT 'WKS' COMMENT '状态：WKS=未开始/JXZ=进行中/YJZ=已截止/YWC=已完成',
    TOTAL_SCORE DECIMAL(5,2) COMMENT '总分',
    QUESTION_COUNT INT COMMENT '题目数量',
    CJR VARCHAR(32) COMMENT '创建人',
    CJSJ DATETIME COMMENT '创建时间',
    GXR VARCHAR(32) COMMENT '更新人',
    GXSJ DATETIME COMMENT '更新时间',
    LJSC INT DEFAULT 0 COMMENT '逻辑删除（0：显示，1：隐藏）',
    INDEX IDX_TEACHER (TEACHER_ID),
    INDEX IDX_STATUS (STATUS),
    INDEX IDX_DEADLINE (DEADLINE)
) COMMENT='作业发布表';
```

## 2. API 接口契约

根据 CLAUDE.md 规范，API 路径规范如下：
- 分页查询：GET `/list`
- 获取详情：GET `/queryById?id=`
- 保存：POST `/save`
- 删除：DELETE `/delete?ids=`
- 导出：GET `/export`

## 7. 数据迁移和备份策略

### 7.1 数据迁移策略

#### 7.1.1 迁移场景

| 场景 | 说明 | 迁移方式 |
|------|------|---------|
| 学校信息变更 | 学校代码、名称变更 | 批量更新关联表 |
| 班级调整 | 学生调班、班级合并 | 更新班级关联关系 |
| 教师调动 | 教师任教班级变更 | 更新教师 - 班级关联 |
| 毕业数据归档 | 学生毕业数据归档 | 数据归档到历史库 |

#### 7.1.2 迁移流程

```
1. 数据备份 → 2. 数据校验 → 3. 执行迁移 → 4. 迁移验证 → 5. 回滚准备
```

#### 7.1.3 迁移注意事项

- 迁移前必须全量备份数据
- 迁移操作应在非业务高峰期执行
- 迁移过程中应暂停相关功能
- 迁移完成后进行数据一致性校验

### 7.2 数据备份策略

#### 7.2.1 备份类型

| 备份类型 | 频率 | 保留周期 | 说明 |
|---------|------|---------|------|
| 全量备份 | 每周日 2:00 | 3 个月 | 完整备份所有数据 |
| 增量备份 | 每天 2:00 | 1 个月 | 备份当天变更数据 |
| 实时备份 | 实时 | 7 天 | binlog 实时同步 |

#### 7.2.2 备份范围

| 数据类型 | 备份方式 | 存储位置 |
|---------|---------|---------|
| 数据库数据 | mysqldump | 本地 + 云端 OSS |
| 文件数据（图片等） | rsync | 本地 + 云端 OSS |
| 配置文件 | 版本控制 | Git 仓库 |
| 日志数据 | logrotate | 本地 + ELK |

#### 7.2.3 恢复策略

| 故障类型 | 恢复方式 | 恢复时间目标 (RTO) |
|---------|---------|------------------|
| 数据误删 | 从增量备份恢复 | < 4 小时 |
| 数据库损坏 | 从全量备份恢复 | < 8 小时 |
| 机房故障 | 切换到灾备中心 | < 2 小时 |

### 7.3 数据归档策略

#### 7.3.1 归档条件

| 数据类型 | 归档条件 | 归档周期 |
|---------|---------|---------|
| 作业数据 | 作业完成后超过 1 年 | 每年一次 |
| 报告数据 | 报告生成后超过 1 年 | 每年一次 |
| 日志数据 | 日志产生后超过 6 个月 | 每月一次 |

#### 7.3.2 归档表结构

```sql
-- 作业数据归档表
CREATE TABLE TB_B_HOMEWORK_PUBLISH_HIS (
    ID VARCHAR(32) NOT NULL PRIMARY KEY,
    -- 与原表相同的字段结构
    ARCHIVE_TIME DATETIME COMMENT '归档时间',
    ARCHIVE_YEAR INT COMMENT '归档年份'
) COMMENT='作业发布历史表';
```

### 8.1 通用错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|---------|
