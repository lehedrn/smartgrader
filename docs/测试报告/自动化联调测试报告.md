## 发现的问题

### 已修复的问题

#### 1. GraduationCap 组件缺失 ✅ 已修复

**问题描述：** 登录页面显示警告 `[Vue warn]: Failed to resolve component: GraduationCap`

**修复方案：** 使用 Element Plus 图标库中的 `School` 图标替代（教育含义相似）

**修改文件：** `src/views/login/index.vue`

**修复版本：** commit `de7711c`

#### 2. Vite 开发服务器 API 代理缺失 ✅ 已修复

**问题描述：** 前端请求 `/api` 无法转发到后端服务器，导致登录失败

**修复方案：** 在 `vite.config.js` 中添加 proxy 配置：
```javascript
proxy: {
  '/api': {
    target: 'http://localhost:8080',
    changeOrigin: true,
  },
}
```

**修改文件：** `vite.config.js`

**修复版本：** commit `de7711c`

#### 3. 前端使用 Mock 数据 ✅ 已修复

**问题描述：** 开发环境下 `vite-plugin-mock` 拦截 `/api` 请求，返回 mock 数据而非真实后端响应

**修复方案：** 
1. 修改 `.env.development` 将 `VITE_MOCK` 设置为 `false`
2. 修改 `vite.config.js` 使用环境变量控制 mock 启用状态

```javascript
viteMockServe({
  localEnabled: env.VITE_MOCK === 'true',  // 从环境变量读取
  prodEnabled: false,
  logger: true,
  mockPath: 'src/mock',
}),
```

**修改文件：** `.env.development`、`vite.config.js`

**修复版本：** commit `afe3bd3`

#### 4. /auth/userinfo 接口 403 错误 ✅ 已修复

**问题描述：** 前端调用 `/api/auth/userinfo` 返回 403 Forbidden

**原因分析：** 
1. 前端调用了错误的接口路径 `/auth/info`（应为 `/auth/userinfo`）
2. 后端没有 JWT 过滤器处理 token 认证

**修复方案：**
1. 前端 `auth.js` 将 `getUserInfo` 接口路径从 `/auth/info` 改为 `/auth/userinfo`
2. 后端创建 `JwtAuthenticationFilter` 统一处理 JWT 认证
3. 后端 `WebSecurityConfig` 添加 JWT 过滤器到过滤器链

**修改文件：** `auth.js`、`JwtAuthenticationFilter.java`（新增）、`WebSecurityConfig.java`、`AuthController.java`

**修复版本：** commit `c2b0fe7`

#### 5. 后端缺少 JWT 认证过滤器 ✅ 已修复

**问题描述：** 后端每个需要认证的接口都要单独处理 token 缺失的情况，代码重复且难以维护

**修复方案：** 创建 `JwtAuthenticationFilter` 继承 `OncePerRequestFilter`：
- 从 `Authorization` header 提取 JWT token
- 验证 token 并设置 Spring Security 上下文
- Token 无效时不影响请求继续（由具体接口决定是否需要认证）

**优势：**
- 所有接口无需单独处理 token 解析逻辑
- 认证逻辑集中管理，易于维护
- 支持受保护接口和无认证接口的混合使用

**新增文件：** `JwtAuthenticationFilter.java`

**修复版本：** commit `c2b0fe7`
